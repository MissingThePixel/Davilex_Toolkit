Launcher and RCS Explorer for seven supported Davilex racing games, with custom
resolutions, aspect-correct HUDs, optional English text, XInput support, Quick
Race and Europe Racer content imports from user-supplied donor games.

Extract the full ZIP and run Davilex Toolkit.exe. Games are not included.
Keep the toolkit's work folder when updating to preserve backup/recovery records.

Includes DDrawCompat and DXWrapper. dgVoodoo and FFmpeg are not bundled.
See README.md, CREDITS.md and licenses for usage, limitations and notices.

Toolkit and RCS Explorer source, compact patch resources and native helper
sources are included in the repository. See BUILDING.md for setup and builds.
